# きらめき3マッチ

自動でながめられる、宝石の3マッチです。通信もアカウントもいりません。`index.html` ひとつで遊べます。

A calm, watchable Japanese match-3. Open `index.html` directly in a browser. Nothing is downloaded at runtime.

## 開きかた

`index.html` をダブルクリックします。音は最初オフ、自動再生はオンです。ステージはクリアしても、手数が尽きても、見ていられるように次へ進みます。

「じぶんであそぶ」にすると、スワイプか、となり同士をタップして入れ替えられます。そろわない入れ替えは戻ります。

設定（自動再生、速さ、音、音量）はこのブラウザに保存します。ファイルを直接開いて保存できない場合は、そのタブを開いているあいだだけ覚えています。

同じフォルダの `manifest.webmanifest` とアイコンは、サーバに置いたとき用です。ページ本体はそれらが無くても動きます。

```bash
python3 -m http.server 8741
```

そのあとブラウザで http://127.0.0.1:8741/ を開きます。
